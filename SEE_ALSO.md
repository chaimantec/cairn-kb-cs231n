# See also

Sibling knowledge bases that cover material CS231N reaches in later lectures. This KB covers only
lectures 1–7 so far, so these are the places to look for a neighbouring treatment of a topic it does
not have yet. Pass the `KB:` URL as `kb` to `kb_read` / `kb_list`, starting at that KB's
`INDEX.md`. Cite them as their own courses, never as CS231N.

- **MIT 6.7960 — Deep Learning** (MIT OpenCourseWare, Fall 2024; Phillip Isola, Sara Beery,
  Jeremy Bernstein). All 24 lectures.
  KB: `https://github.com/chaimantec/cairn-kb-mit-6-7960` — pass this as `kb`.
  A theory-leaning deep-learning course that overlaps CS231N's middle: training neural nets and
  backpropagation, convolutional architectures ("Architectures: Grids"), transformers,
  representation learning (reconstruction- and similarity-based, the background to CS231N's
  self-supervised learning lecture), and three lectures on generative models. Start at
  [INDEX](https://raw.githubusercontent.com/chaimantec/cairn-kb-mit-6-7960/main/INDEX.md).

- **CS224N — Natural Language Processing with Deep Learning** (Stanford, Spring 2024;
  Christopher Manning). All 23 lectures.
  KB: `https://github.com/chaimantec/cairn-kb-cs224n` — pass this as `kb`.
  The language-side counterpart: its attention and self-attention/transformer lectures derive
  the mechanism CS231N's "Attention and Transformers" lecture applies to vision, and it covers the
  language half of vision–language models. Start at
  [INDEX](https://raw.githubusercontent.com/chaimantec/cairn-kb-cs224n/main/INDEX.md).

- **CS224R — Deep Reinforcement Learning** (Stanford, Spring 2025; Chelsea Finn). All 19
  lectures.
  KB: `https://github.com/chaimantec/cairn-kb-cs224r` — pass this as `kb`.
  Imitation learning and reinforcement learning for robots — the methods behind CS231N's robot
  learning and embodied-intelligence lectures. Start at
  [INDEX](https://raw.githubusercontent.com/chaimantec/cairn-kb-cs224r/main/INDEX.md).
